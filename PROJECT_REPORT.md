## 1. INTRODUCTION

A portfolio website is a personal website used to present a student's profile, skills, education, projects, achievements, resume and contact information in an organized manner. The project described in this report is a modern responsive portfolio website designed to provide a professional online presence and make important career information easy to access.

The website contains Home, About, Skills, Projects, Education, Resume and Contact sections. It also includes responsive design, a dark/light theme option, animated elements and project cards.

## 5. PROJECT DEVELOPMENT

### Step 1: Project Structure
The website is organized into `index.html`, `style.css`, `script.js`, an `images` folder for the profile photo and project graphics, and a `resume` folder for the PDF resume.

### Step 2: HTML Structure
The HTML file defines the navigation bar, hero, About, Skills, Projects, Education, Resume and Contact sections.

### Step 3: CSS Styling
CSS creates the modern visual appearance, responsive layouts, glass-effect cards, hover effects, animations and dark/light themes.

### Step 4: JavaScript
JavaScript provides typing animation, theme preference, mobile navigation, scroll-reveal effects, project filtering, back-to-top behavior and contact-form feedback.

### Step 5: Deployment
The files are uploaded to a public GitHub repository and GitHub Pages is configured to deploy from the main branch and root folder.

## 6. PROJECT FEATURES

1. **Responsive Navigation** – Easy movement between portfolio sections across mobile, tablet, and desktop viewports.
2. **Animated Home Section** – Introductory heading and animated role text (*"Full Stack Developer | BCA Student"*).
3. **Profile Photo** – Displays the user's profile image with status indicator.
4. **About Section** – Gives a personal and academic introduction highlighting passions in web development and computer vision.
5. **Skills Section** – Presents technical skills visually (HTML5, CSS3, JavaScript, Python, Node.js, Flask, SQL/MongoDB, OpenCV, YOLO, Arduino).
6. **Project Cards** – Displays project cards highlighting:
   - *Classroom Automation System* (Computer Vision using YOLO & Arduino relay module)
   - *ReUseMarket* (Flask-based used-products marketplace)
   - *Personal Portfolio Website* (Modern responsive frontend)
7. **Education & Certifications Section** – Presents BCA academic information along with credentials from Infosys Springboard, Viksit Bharat Young Leaders Dialogue, and Cyberverse Foundation.
8. **Resume Section** – Provides a downloadable PDF resume.
9. **Dark/Light Mode** – Allows visitors to switch between dark and light themes seamlessly.
10. **Contact Section** – Displays contact details and frontend form feedback.

> **Note:** The current contact form provides frontend feedback only. A backend or form service is required for storing or sending actual messages.
